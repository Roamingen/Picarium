## 6. 已知坑（会重复踩的）

1. **改完 `app.js` / `style.css` 必须 `cargo build -p stickerbox`**：前端资源编进二进制，不重建会拍到旧界面（本轮踩了两次，截图 sha 一模一样就是它）。
2. **`accept.ps1` 会把临时库 `settings.json` 写回 `"startHidden": true`**，之后 `shot_main.ps1` 找不到窗口、静默不产出图片。截图前先把它改回 `false` 再启动。
3. `shot_main.ps1` 把窗口设成 1000×660，但 WebView 的 `innerHeight` 报 700，截图会从底部裁掉约 40 CSS px；面板高度按窗口算时要留余量（本轮筛选用 520 封顶）。
4. `cargo build` 报 `拒绝访问 (os error 5)` 是 app 还在跑锁住 exe，`taskkill //F //IM stickerbox.exe` 再编。
5. 用 python 按字符串 index 删代码段很危险（`document.addEventListener('mousedown'` 首次出现位置在目标块之前，把中间段复制了一份，5133→6685 行）。**删除/替换用 edit 工具或先 assert count==1**。
6. 临时库标签会被 accept 清空；想截有数据的面板要先把 `index.json` 里的 assets 塞上标签（用 `ensure_ascii=False` 写回，控制台乱码不影响文件）。
7. 安卓模拟器这轮退出过一次（后台 job 结束）；再起用 `docs/26-安卓模拟器速查.md` 的 `ops_bash` 后台直跑方式，别用 ps1。
