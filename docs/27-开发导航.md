## 2. 数据流与关键概念

1. 启动：`main.rs::main()` 取 `STICKERBOX_HOME`（或候选目录）→ `Library::open` → `AppState`。
2. 列表：前端 `refresh()` 调 `invoke('list_assets', {q, group, limit, filters})`。
3. 命令层：`commands::list_assets` 把过滤条件解析成 `AssetFilters`，再调 `Library::search` / `ordered`。
4. 前端渲染：`render(items)` 把结果放进 `shownItems`；卡片元素用 `data-index` 指回它。
5. 写操作：`main.rs` 的 Windows 命令（复制文件、删到回收站、导入）或 `commands.rs` 的共享写操作，最后都由 `Library` 落 `index.json`。
6. 设置：`get_settings` 读整份 JSON；`patch_settings` 合并写入并触发 side effects（热键、开机自启、面板尺寸等）。
7. 图片地址：缩略图用 `http://thumb.localhost/<sha>`；要原图（动图）用 `convertFileSrc(path)`，走 asset 协议。

`Asset` 里最常用的字段：`sha`（唯一键）、`name`、`path`、`ext`、`animated`、`w/h`、`bytes`、`tags`、`groups`、`starred`、`used_at`、`created_at`。

### 3.2 渲染与光标

- `refresh()`：取列表 → `render()`；分页“加载更多”也走它。
- `render(items)`：重置 `grid`，虚拟滚动开启时 `renderVirtual(true)`，否则逐张 `buildCard`，最后 `paintCursor()`。
- `renderVirtual`：只挂视口附近的卡片；**屏幕外的卡片不存在于 DOM**，不要用 `querySelectorAll` 统计全部。
- `buildCard(a, idx)`：卡片骨架、鼠标事件、右键、双击编辑、拖拽；`data-index` 是 `shownItems` 的下标。
- `paintCursor()`：切换 `.card.cursor`、更新 `--cursor-phase`；**同时负责启动/恢复光标所在卡片的动图**（`cursorAnimCard` / `cursorAnimTimer`）。
- `buildCard` 的 `mouseenter` 只负责“鼠标悬停预览 + 把 cursor 移过来”；`mouseleave` 在光标还停在该卡时不收回动图。
- 动图规则：`hoverDelay` 来自设置，0 = 关闭；`a.animated` 为真才切原图；切原图用 `convertFileSrc(a.path)`，回缩略图用 `thumbSrc(a.sha)`。

### 3.3 键盘

- `buildKeymap(user)` 生成 `keymap`；单字符/序列区分大小写，组合键统一小写。
- `moveCursor(delta)`：改 `cursor` → `paintCursor()`；虚拟列表会按需滚动/重渲染。
- `executeAction(action, count)`：动作分发；新增键位先看 `docs/15-按键表.md`。
- which-key：前缀键（如 `g`）后显示下一层；改键位要同时改 `docs/15` 和设置页。

## 4. 快贴面板 `panel.html`

独立窗口（label `panel`），只加载 `style.css` + `font-config.js`，**不加载 `app.js`**；逻辑是页面底部唯一一段内联 JS。主窗口与面板通过 Tauri 事件和共享设置通信。

### 4.1 打开与关闭

1. 全局热键（默认 `Ctrl+Alt+Space`）→ `main.rs::toggle_panel`。
2. 面板已显示则 `hide`；否则 `show` + `set_focus` + `emit('panel-open')`。
3. 面板监听 `panel-open`：清空输入 → `applySettings()` → `loadFacets()` → `search('')` → 聚焦输入。
4. 失焦自动隐藏（`main.rs` 的 window event）；`hide_panel` 命令也可收起。
5. 面板窗口配置在 `src-tauri/tauri.conf.json`：720×520、无边框、置顶、不进任务栏、不可缩放、默认隐藏。

### 4.2 面板自己的状态

- `items`、`cursor`、`hoverDelay`、`cursorSpeed`、`cursorColors`、`panelKeys`。
- `render()` 建 `.panel-card`，`data-index` 对应 `items`；`paint()` 负责 active 状态、滚动可见、动图预览、光标环相位。
- **动图属于光标**：`paint()` 对当前 active 的 `animated` 卡片在 `hoverDelay` 后切原图；移走时恢复缩略图；打开/搜索重渲染也走 `paint()`，所以第一张是 GIF 时会直接播。
- 鼠标悬停：`mouseenter` 把 `cursor` 移到该卡并 `paint()`；`mouseleave` 只收提示，不单独收回动图（避免和键盘光标打架）。
- 边界：`move()` 在 `next === cursor` 时直接返回，避免把等待中的动图计时器重置。
- 复制：`animated` 走 `copy_asset_file`（保住动画），否则 `copy_asset`；然后 `hide_panel`。

### 4.3 光标环

- 颜色/速度来自设置 `cursorColors` / `cursorSpeed`；`applyCursorRing()` 动态写 `<style id="cursor-style">`。
- 规则目标 `.panel-card.active::before`；CSS 里 `.panel-card` 必须有 `position: relative`，伪元素才能贴合圆角。
- 环的 `background: conic-gradient(from var(--cursor-angle), ...)` 和 `animation` 必须写在伪元素自己的规则里；`@property --cursor-angle` 在 `style.css` 定义。
- 颜色数 >1 时末尾补首色，避免 0°/360° 接缝。

## 5. Rust 壳

### 5.1 `main.rs`（桌面）

- 入口：`main()`，先处理 `probe` / `diag` / `scan` 命令行，再取单实例、开库、读 `settings.json` 恢复热键/隐藏启动。
- 窗口：`show_main`、`toggle_panel`、`set_pinned`、`set_window_size`、`set_panel_position`、`hide_panel`、`hide_font_settings`。
- 系统：`register_hotkey`、`set_hotkey`、`set_clip_hotkey`、`toggle_clipboard`、`clipboard_sources`、`set_clipboard_enabled`、`set_autostart`。
- 写操作：`copy_asset`、`copy_asset_file`、`copy_assets_files`、`batch_delete`、`import_paths`、`open_asset`、`open_library_folder`、`update_asset`。
- 设置：`patch_settings`（合并 + side effects）、`export_settings`、`import_settings`。
- 诊断：`selftest_mode`、`ui_state`、`selftest_report`、`js_log`。
- 自测/截图用环境变量：`STICKERBOX_SELFTEST=accept|perf`、`STICKERBOX_UI_STATE=<state>`。

### 5.2 `lib.rs` / `commands.rs`（共享）

- `lib.rs`：模块声明、`AppState` 注入、`thumb` 协议注册；安卓的 `mobile_entry_point` 也在这里。
- `commands.rs` 只做“库文件 + 共享逻辑”，不能碰 Windows API，否则安卓编译/运行会坏。
- 典型命令：`list_assets`、`get_asset`、`themes_list`、`group_*`、`tag_*`、`trash_*`、`get_settings`、`set_fonts`、`share_assets`、`import_paths_simple`。
- 过滤：`parse_filters` + `apply_filters` 在共享层，前端只传 JSON 字符串。

### 5.3 其它

- `state.rs`：`AppState`；`candidate_roots()` 按 `STICKERBOX_HOME` → `USERPROFILE\Picarium`（迁移前旧 `USERPROFILE\StickerBox` 优先）→ `LOCALAPPDATA\Picarium`（旧 `LOCALAPPDATA\StickerBox` 兜底）→ 当前目录。
- `thumb.rs`：`thumb://<sha>`，`?raw=1` 返回原图；回收站里的图也能取。
- `clipboard.rs`：Windows 剪贴板监听/写入；`recycle.rs`：系统回收站。
- `platform/`：桌面/安卓能力边界（分享、相册、文件选择、打开）；新增平台能力先加 trait，不要直接在命令里写平台判断。

## 6. 核心 `crates/core/src/lib.rs`

单文件约 2200 行，`Library` 是唯一入口。重点方法（按功能）：

- 生命周期：`open`、`save`、`root`、`assets`。
- 导入：`scan_folder`、`import_file`、`import_image_bytes`（sha 去重、blob 分桶、缩略图）。
- 搜索：`search(q, group, limit)`、`match_score`、`pinyin_of`；支持中文/全拼/首字母/标签/分组。
- 更新：`update`、`set_star`、`touch_used`、`set_asset_tags`、`add_tags`/`remove_tags`。
- 分组：`add_group`、`clear_groups`、`create_group`、`rename_group`、`remove_group`、`set_group_order`、`set_pinned_groups`、`set_group_cover`。
- 标签：`create_tag`、`rename_tag`、`merge_tags`、`delete_tag`。
- 排序：`ordered`、`set_order`；特殊 key 与前端侧栏一致。
- 回收站：`trash`、`search_trash`、`restore`、`delete_forever`、`purge_trash`、`purge_expired_trash`、`trash_days`。
- 统计：`group_stats`、`tag_stats`、`starred_count`、`recent_count`、`stats`。
- 缩略图/动图：`ensure_thumb`、`thumb_path`、`is_animated`（GIF/APNG/动画 WebP 只看文件头）。
- 测试：文件底部 `mod tests`，20 条；改核心逻辑必须跑 `cargo test -p stickerbox-core`。

注意：`index.json` 是唯一索引真源；`save()` 的写入时机影响“改完立刻刷新”是否能看到。批量操作尽量在 `Library` 内一次完成，不要在命令层循环 `save`。

### 8.2 隐藏 CDP（新增交互/动图/光标时用）

这是当前推荐的“不弹窗”验证方式，硬规则见 `AGENTS.md` §2.1：

```bash
export STICKERBOX_HOME="$TEMP/stickerbox-panel/lib"
export WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9333 --remote-allow-origins=*"
"$LOCALAPPDATA/StickerBoxBuild/target/debug/stickerbox.exe" &
# 不要按 Ctrl+Alt+Space；直接连 http://127.0.0.1:9333/json 里的页面
```

要点：

- 设置里先写 `{"startHidden": true}`，两个窗口都不可见；用 Win32 `IsWindowVisible` 抽查，`document.visibilityState` 在隐藏 WebView2 里仍可能是 `visible`。
- 面板不用打开：隐藏页面里直接 `search('')` / `render()` / `paint()` 就能验证。
- 主界面用精确 URL `http://tauri.localhost`，**不要**用 `tauri.localhost/` 子串匹配（会命中 `panel.html`）。
- 截图用 CDP `Page.captureScreenshot`，或 `.tools/shot_main.ps1`；不要为了截图把窗口弹出来。
- 参考脚本：`.demo/gif_hidden_check.py`（不提交，验证首屏/键盘/悬停动图）；`.demo/panel_live_check.py`（上一版，含旧的 ensure 热键逻辑，别直接复用）。
- 自定义行为 accept 不一定覆盖，写针对性的 CDP 断言，不要只靠“看起来对”。

### 8.3 自测/截图状态

- `STICKERBOX_SELFTEST=accept`：跑前端断言并写 `selftest-report.json`。
- `STICKERBOX_SELFTEST=perf`：性能套件。
- `STICKERBOX_UI_STATE=settings:keys`、`filters`、`tagmanage`、`whichkey` 等：启动后直接进入对应界面；配合 `.tools/shot_main.ps1`。

## 9. 改代码的规矩（摘要）

- 一轮只做 1 个可验收小批，做完停下等审；每批说明改什么、验证什么、预计动哪些文件。
- UI 改动原则上先出 `docs/mock/` HTML 预览；小修也要在汇报里说明改了什么。
- 不猜：先 `grep` / 读源码 / 跑一条命令确认，再下结论。
- commit 前先汇报；格式 `<type>(<scope>): 中文摘要`；一批一个 commit。
- 功能/修 bug 后按 `0.MINOR.PATCH` 升版本：PC 真源 `src-tauri/tauri.conf.json`（`Cargo.toml` 同步），安卓真源 `tauri.android.conf.json`；不擅自跑 release。
- 不往 git 加图片/二进制；截图放 `.demo/`（gitignore），用 `present` 给用户看。
- 不读微信/QQ 私有数据；不碰用户真实库做删除/批量测试；不擅自改全局配置。
- `src-tauri/gen/` 是生成物，别手改，也别对它做大范围 grep。

## 10. 常见坑

1. **app.js 和 panel.html 是两套逻辑**：改主界面不会自动改面板，反之亦然；共用的只有 `style.css` 和设置。
2. **虚拟列表**：`shownItems` 是全部，DOM 只有视口附近；键盘移动/统计时不要假设卡片都在。
3. **`data-index` 是 `shownItems` 下标**，不是 sha；回收站/单图模式会换 `shownItems`，跨视图操作先确认当前列表。
4. **光标动图**：光标和鼠标悬停都能触发，状态在 `cursorAnimCard`；`mouseleave` 不能无条件恢复，否则会把光标还在播的图收掉。
5. **面板光标环**：`.panel-card` 没有 `position: relative` 时伪元素环会跑位；环的 `animation` 必须写在 `::before` 自身规则里，否则 `--cursor-angle` 不转。
6. **`hoverDelay = 0`** 表示关闭预览；所有新增播放逻辑都要尊重这个开关。
7. **动作/键位**：`buildKeymap` 对组合键和单字符大小写规则不同；新增键位要同步 `docs/15`、设置页、which-key。
8. **设置**：`get_settings` 返回整份 JSON；写设置统一走 `patch_settings`，不要前端直接写 `settings.json`。
9. **回收站**：删除先看 `deleteMode`（回收站/彻底删除）；批量删除走后端，别在前端循环单删。
10. **CDP**：`Panel.ev` 不要重复解包；`Runtime.evaluate` 的 `awaitPromise` 对会挂起的 Promise 很危险；先核对超时单位。
11. **测试窗口**：不要在自动化里按全局热键、`show`、`set_focus`；需要用户看见时先问。
12. **版本**：PC 与安卓独立；改完配置后设置页显示的是 Cargo 版本，不是 `package.json`。

## 13. 浏览器导入扩展（extension/）

- 结构：MV3 + TypeScript + esbuild，产物在 `extension/dist/`（含 manifest，直接被 Chrome 加载）；源码 `src/background.ts`（右键菜单 + 抓图 + 调桥）、`src/content.ts`（B 站悬浮钮）、`src/lib/{bridge,media,overlay}.ts`。
- 改完跑：`cd extension && npm run build`，然后 `chrome://extensions` 点「重新加载」，再刷新 B 站页面（content script 只在页面加载时注入，重载扩展不回溯已开标签）。
- 验证：`npm run typecheck`、`npm test`（11 条：URL 归一化/格式嗅探/base64/data URL + 按钮几何）。
- 桥：`src-tauri/src/bridge.rs`，`127.0.0.1:17800`，`GET /ping`、`POST /import`、`POST /copy`（库内文件）、`POST /copy-raw`（仅复制，不落库）；页面钮「下载到本地」走 `downloads` 权限 + data URL，不经过桥；token 在 `bridge.rs::TOKEN` 和 `src/lib/bridge.ts::TOKEN` 两处，改要同步并重新构建。
- 页面钮没法用无头浏览器验（Chrome 不注入 unpacked 扩展的 content script）：用 `.demo/p3-dom-test*.mjs` 把 `dist/content.js` 注入普通测试页 + stub `chrome.runtime.sendMessage`；真实 B 站靠手动回归。
- 出钮范围只限评论区图片（`/bfs/new_dyn/`、开放 Shadow DOM `<bili-comments>`）和点开的大图；视频封面（`/bfs/archive/`、`b-img__inner`）不出钮。细节见 `docs/28-浏览器插件方案.md` 与 `extension/README.md`。
