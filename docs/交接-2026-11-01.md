## 3. 本轮修了什么（都已实测）

- **R8 裁 JNI 桥**：`proguard-rules.pro` keep `ShareBridge/PickerBridge/InboxBridge/MediaCopy`，否则 release 里分享/导入静默失效。
- **FAB**：改为「导入图片」弹层（相册导入 / 取消），不再只弹 toast。
- **键盘遮挡**：`MainActivity.kt` 用 `WindowInsetsCompat.Type.ime()` 给内容区补 bottom padding；`innerHeight` 867→554，弹层在键盘上方。
- **预览两级**：预览页跟主题走（卡片 + 信息条）；点图片进 `#lightbox` 全屏黑底，双指缩放 1–5、拖动、双击 2.6、轻点关闭、左右切换。
- **主题变量**：`--icon/--viewer-bg/--card-bg/--card-line/--panel-fg/--panel-dim`；新增主题只加变量，禁止硬编码色值。
- **文件信息**：`.kvrow` 用 `--fg/--panel-dim`，浅色不再是白字白底。
- **加入分组**：多选底栏「分组」；单张预览标签行「加入分组」；`add_to_group/batch_ungroup/clear_groups` 已搬进共享命令层。
- **置顶**：分组详情右上角 pin 按钮；分组页排序「置顶优先（按置顶顺序）」；置顶卡片右上角 pin 标；首页置顶条只显示置顶分组。
- **选区不闪**：多选/取消不再 `renderGrid()` 重建全部卡片，改为就地切 class（长按或点选都不会闪）。
- **回收站多选**：长按进入多选，底部「恢复 / 彻底删除」批量操作；切 tab 自动退出。
- **聚焦边**：输入框/新建分组去掉浏览器默认黄色 focus ring，改主题色 outline。
- **AGENTS**：新增 §9「前端/UI 改动必须先出 HTML 预览图并等确认」。

## 5. 已知坑

1. **NOC 图片格式**：`content://` 无扩展名，必须读文件头嗅探（`MediaCopy.java`），否则 PNG 存成 `.jpg`，缩略图空白。
2. **R8**：JNI 类必须整类 keep；release 里静默失败优先怀疑它。
3. **WebView 内部滚动容器**：安卓合成错误会画成条纹，必须整页滚动 + sticky 头 + fixed 底栏。
4. **`[hidden]` 被作者样式覆盖**：`mobile.css` 顶部有 `[hidden]{display:none!important}`。
5. **未分组**：core 用 `group=""`，不是 `__none__`（桌面哨兵）。
6. **targetSdk 35**：`adjustResize` 不生效，必须用 IME inset。
7. **同 AVD 启动**：杀掉旧 emulator 进程，或 `-read-only`。
8. **键盘/弹层**：底部弹层输入框要等键盘 inset 生效后再定位；`innerHeight` 会缩。
9. **置顶数据**：`index.json` 的 `pinned_groups/group_covers/group_order`，桌面端也会读。
10. **测试库**：`.demo/libbackup/StickerBox`（debug 包用 `run-as` 备份/恢复）。
