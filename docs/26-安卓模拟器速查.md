# 26 · 安卓模拟器速查（bash 直启，不用 ps1）

> 面向：人和 agent。目标是用**最少 token / 最少试错**把模拟器拉起来、装包、截图。
> 完整构建与签名见 `docs/25-安卓构建、签名与模拟器.md`；这里只讲日常怎么用。
>
> **不要用 `scripts/android-emu.ps1` 起模拟器**：它经 PowerShell / `Start-Process` 拉起模拟器，会在用户桌面弹一个终端窗口。
> agent 一律用 `ops_bash` 的 `run_in_background` 直接跑 `emulator.exe`；**起来后不要关**，用户还要在上面测试。

## 1. 起模拟器（先查再起）

```bash
export ANDROID_HOME="${ANDROID_HOME:-${LOCALAPPDATA:-$HOME/AppData/Local}/Android/Sdk}"
A="$ANDROID_HOME/platform-tools/adb.exe"
"$A" devices        # 有 emulator-xxxx  device 就复用，跳到第 2 步
```

没有设备时，用 `ops_bash` + `run_in_background: true`：

```bash
mkdir -p .demo
exec "$ANDROID_HOME/emulator/emulator.exe" -avd Medium_Phone_API_35 \
  -no-boot-anim -gpu swiftshader_indirect > .demo/emulator.out.log 2>&1
```

- job 起来后**不要 kill**；要关模拟器必须先得到用户明确同意。
- 日志看 `.demo/emulator.out.log`；报 `running multiple emulators` 说明已有实例，复用即可，别强起。
- 换 AVD：`"$ANDROID_HOME/emulator/emulator.exe" -list-avds`，改 `-avd`。
- 不要用 `-Fresh` / `-wipe-data` / `adb emu kill`。

## 2. 等开机完成

```bash
"$A" wait-for-device
while [ "$("$A" shell getprop sys.boot_completed 2>/dev/null | tr -d '\r')" != "1" ]; do sleep 2; done
```

冷启动 20–40 秒。不要跳过这步直接 `install`。

## 3. 装包 / 拉起 / 截图

```bash
"$A" install -r src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
"$A" shell monkey -p dev.stickerbox.desktop -c android.intent.category.LAUNCHER 1
sleep 9   # 首次进图库约 8–9 秒白屏
"$A" exec-out screencap -p > .demo/emu.png
```

- 截图放 `.demo/`（已 gitignore），不要入库。
- 点按 `"$A" shell input tap x y`；长按 `"$A" shell input swipe x y x y 800`；返回 `input keyevent 4`。
- 系统选择器（相册 / 文件 / 分享面板）在前台时，WebView 的 CDP `Runtime.evaluate` 会挂住：先 `input keyevent 4` 回前台。

## 4. 坑（按出现频率排）

| 坑 | 现象 | 正解 |
|---|---|---|
| 用 ps1 起模拟器 | 用户桌面弹终端窗口 | agent 改用 `ops_bash` 后台直接跑 `emulator.exe`（见 §1） |
| 把模拟器关了 | 用户没法测试 | 不要 kill 后台 job / `adb emu kill`，除非用户明确说要关 |
| `adb` 不在 PATH | `adb: command not found` | 用 `$ANDROID_HOME/platform-tools/adb.exe`，别去改 PATH |
| MSYS/Git Bash 改写路径 | `adb shell ls /sdcard/...` 变成 `C:/Program Files/...` | `export MSYS_NO_PATHCONV=1` |
| 冷启动白屏 | 截图全白，只有状态栏 | 模拟器 OK 后 App 还要 8–9 秒才渲染；`sleep 9` 再截 |
| 截图是坏的 | PNG 打不开 / 只有几 KB | bash 用 `adb exec-out screencap -p > x.png`（二进制安全）；PowerShell 的 `>` 不行 |
| 杀模拟器后立刻起新的 | 新实例拿着刚死的 serial 白等 | 先轮询到 `adb devices` 里没有 `emulator-*`，再启动 |
| 同一 AVD 已在运行 | `emulator: ERROR: running multiple emulators` | 复用已有实例，不要 `-Fresh` |
| CDP 连不上 / eval 卡死 | `Runtime.evaluate` 超时 | 页面必须在前台；选择器在前台时先 `keyevent 4` |
| `am start` 模拟分享失败 | `SecurityException: has no access to content://...` | adb 无法伪造 uri 权限，分享入口只能真机或应用内触发 |

## 5. 验收标准

- `adb devices` 里有 `emulator-5554  device`，`getprop sys.boot_completed` = `1`；
- `adb shell dumpsys window | grep mCurrentFocus` 里出现 `dev.stickerbox.desktop`；
- 截图 PNG **大于 100 KB** 且不是纯白。

## 6. 换新 AVD / 空库测试

新建的 AVD 是干净系统，App 装上去是**空库**（0 张），正好用来测「导入」和首次启动：

```bash
"$ANDROID_HOME/emulator/emulator.exe" -list-avds                  # 看有哪些
"$ANDROID_HOME/emulator/emulator.exe" -avd Pixel_4_API_35 \
  -no-boot-anim -gpu swiftshader_indirect
```

装包/拉起照 §3。每台 AVD 的数据各自保留；要清空用 `-wipe-data`（会重建 userdata，慢但干净）。
要造测试图：`adb push 图片 /sdcard/Pictures/`，再在 App 里导入。

## 7. 旧脚本怎么处理

`scripts/android-emu.ps1` 保留给**人工手动**用（一条龙：复用/起/装/拉/截），agent 不要调用：
它弹终端、`-Fresh` 还有锁坑。agent 按上面的 bash 顺序做，job 用 `ops_bash` 管理。
