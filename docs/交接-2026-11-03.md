## 6. 已知坑（会重复踩的）

1. **模拟器不要再交给 `scripts/android-emu.ps1` 起**：它会弹一个 Windows Terminal；而且把脚本后台 job kill 掉会把模拟器一起带下线。当前做法（用户认可）：`ops_bash` 里 `run_in_background` 直接跑
   `exec "$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd Medium_Phone_API_35 -no-boot-anim -gpu swiftshader_indirect > .demo/emulator.out.log 2>&1`
   **这个后台 job 不要 kill，模拟器要一直开着**；装包后 `am force-stop` + `am start`（或 monkey）。第一次装完冷启动 WebView 可能白屏 10–15 秒，别急着判断崩溃。
2. **构建 target 在 AppData**：`.cargo/config.toml` 的 `target-dir = C:/Users/13066/AppData/Local/StickerBoxBuild/target`。本会话是 `danger-full-access` / approval 关闭才写进去；如果新会话回到 workspace-write，`cargo build` 会 `os error 5`，不要自己加 `sandbox_permissions` 硬闯，先看当前权限，必要时让用户切权限。
3. **标签生命周期别退回旧实现**：现在标签是独立登记（`known_tags`），0 引用仍保留；不要再靠资产里的 tags 反推标签列表。`delete_tag` 必须同时清 assets + trash + registry，否则回收站恢复会复活旧标签。
4. **`tag_stats` 现在包含 0 引用**：筛选面板用 `count > 0` 过滤；批量标签面板和管理页显示 0；改这里要同时看三处。
5. **「添加到」的搜索兼新建**：`#pick-new`/`#pick-newrow` 已删除，别再找回旧入口；新建行是 `.pickcreate`，点行/回车都走 `createPickGroup(name)`；中文输入法回车有 `e.isComposing` 保护；建组后 `clearPickQuery()` + `revealPicked()`。
