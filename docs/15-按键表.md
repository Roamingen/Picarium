# 15 · 按键表（现状 + 规划）

> 2026-10-30 · 全键盘操作的设计底稿

---

## 1. 设计原则

1. **一个动作 = 一组按键**（多对一），例如「向上」可以同时是 `k`、`↑`、`Ctrl+K`；
2. 按键表存在 `settings.json` 的 `keymap` 里，可导入导出；
3. 后面加 vim 风格只改 JSON，不改代码；
4. 序列键（`gg`、`dd`）留出「多段」结构，暂时不用。

```json
{
  "keymap": {
    "up":    ["k", "arrowup"],
    "down":  ["j", "arrowdown"],
    "left":  ["h", "arrowleft"],
    "right": ["l", "arrowright"],
    "copy":  ["enter", "y"]
  }
}
```

## 3. 已实现

### P1：主界面键盘导航（已实现）

| 动作 | 默认按键 | 状态 |
|---|---|---|
| 上 / 下 / 左 / 右 | `k` `j` `h` `l` + 方向键 | ✅ |
| 首 / 尾 | `gg` / `G` | ✅ 序列键已支持 |
| 复制 | `Enter` / `y` / `Ctrl+C` | ✅ |
| 选中切换 | `x` | ✅ |
| 设置锚点 / 区间选 | `v` 两次 | ✅ |
| 全选 | `Ctrl+A` | ✅ |
| 删除到回收站 | `dd`（弹确认，`y`/`n`） | ✅ |
| 编辑信息 | `c` | ✅ |
| 聚焦筛选 | `/` / `Ctrl+F` | ✅ |
| 退出筛选 | `Esc`（输入框内） | ✅ |
| 切分组 | `Ctrl+J` / `Ctrl+K` | ✅ |
| 新建分组 | `Ctrl+N` | ✅ |
| 退出多选 | `Esc` | ✅ |

按键表可自定义：存在 `settings.json` 的 `keymap` 字段，未写的动作走默认值。

### 改键与提示（已实现）

- 设置 → **按键**：列表式改键（不是屏幕键盘，避免配列差异）；
- 点「改键」后按新键；连按两下字母可设序列（`gg`/`dd`）；`Esc` 取消；`Backspace` 删除单个绑定改为点 × 删除；
- 冲突检测：同一键绑给两个动作时拒绝保存并提示；
- **which-key**：按下前缀（如 `g`）时浮出候选面板，1200ms 内按候选键继续；超时自动收起；
- **速查**：按 `?` 打开完整按键表（按上下文分组），`Esc` 关闭。

### 输入框与弹窗

- 编辑弹窗：`Esc` 先让输入框失焦，再按一次关闭；
- 输入框内 `j/k` 不拦截（正常打字）；`Ctrl+J` / `Ctrl+K` 在字段间移动。

## 4. 需要先解决的技术点

1. **序列键**：`gg`、`dd` 需要「按键缓冲 + 超时（约 500ms）」；
2. **输入框隔离**：焦点在输入框时，单字母快捷键必须失效，只保留 `Esc`；
3. **冲突检测**：保存 keymap 时检查同一按键是否被两个动作占用；
4. **提示**：底部状态栏显示「已按下 g，等待第二个键」。

---

## 5. 暂不支持

- 鼠标手势；
- 组合键超过 3 个（如 `Ctrl+Alt+Shift+K`）——技术上可以，但先限制，避免误触。

## 6. 键名对照表（界面显示与存储值）

| 存储值 | 显示 | 说明 |
|---|---|---|
| `j` `k` `h` `l` | J K H L | 单个字母 |
| `G` | G | 大写字母（Shift 输入） |
| `gg` / `dd` / `kk` | GG / DD / KK | 序列键，连按 |
| `ctrl+d` | Ctrl+D | 组合键统一小写存储 |
| `shift+tab` | Shift+Tab | |
| `escape` | Esc | 命名键 |
| `enter` / `tab` / `space` | Enter / Tab / Space | 命名键 |
| `backspace` / `delete` | ⌫ / Del | |
| `arrowup` `arrowdown` `arrowleft` `arrowright` | ↑ ↓ ← → | |
| `pageup` / `pagedown` | PgUp / PgDn | |
| `home` / `end` / `insert` | Home / End / Ins | |

命名键（上表里非单字母、非组合的那些）**不参与序列前缀判断**，所以按 `p` 不会再提示 `pagedown` 的 `a`。

## 7. 计数前缀

支持 vim 风格的数字：`12j`、`2l`、`3h`、`12gg`、`2PageDown`。
- 数字先累计，底部显示「计数 12 …」；
- `12gg` 跳到第 12 项；
- 移动类动作为「动作 × 12」。

## 8. 新增动作（批量 / 回收站）

| 动作 | 默认键 | 说明 |
|---|---|---|
| 复制并记住 | `y` | 复制选中（多选走多文件剪贴板），并退出多选；`p` 用 |
| 粘贴到光标后 | `p` | 同组内 = 移动排序；跨组 = 复制到当前分组；**空分组也能粘** |
| 加入分组 | `a` | 打开分组选择器（勾选加入/取消） |
| 移出当前分组 | `A` | 只在分组视图有效 |
| 添加标签 | `t` | 输入标签名，批量添加 |
| 收藏/取消收藏 | `s` | 按当前状态切换 |
| 恢复（回收站） | `r` / `Enter` | 从回收站恢复到库 |
| 彻底删除（回收站） | `dd` | 确认后按删除方式处理 |

## 9. 改键规则

- 「添加键」是**追加**一个绑定，不覆盖原有绑定；
- 删除单个绑定点 chip 上的 ×；
- 冲突规则：**相同**或**前缀重叠**都算冲突（已经有 `k` 时，`kk`、`kj`、`kkk` 都非法）；
- 冲突时提示具体冲突的动作名；
- 改键立即生效，无需重启。


## 10. 大小写严格区分

- 存储与匹配都**区分大小写**：`j` 与 `J` 是两个键，`H` 不会触发 `h`；
- 界面显示保持原样（`j` 显示 j，`G` 显示 G）；
- 组合键（`ctrl+d`、`shift+tab`）统一小写存储，字母部分不区分大小写；
- 序列同样区分：`gg` 与 `gG` 不同。

## 11. 鼠标按键（通用编号）

- 存储值统一为 `mouse<编号>`：`mouse1` 左键、`mouse2` 中键、`mouse3` 右键、`mouse4` 起为其它键；
- 显示为「鼠标左键 / 鼠标中键 / 鼠标4 …」，不再猜测“侧键前/后”，任何鼠标都一致；
- 支持**修饰键 + 鼠标**：`ctrl+shift+mouse1`（Ctrl+Shift+左键）；
- 默认绑定：
  - 单击（`mouse1`）= 复制；
  - `ctrl+mouse1` = 切换选中；
  - `shift+mouse1` = 锚点区间（与 `v` 等价）；
- 右键保留给菜单，不参与绑定；未绑定时行为与以前一致。

## 11.1 快贴全局热键

- 设置 → 按键 → **系统快捷键**（置顶单独一块），点「修改」后直接按新组合；
- 捕获逻辑与内部按键一致：浮动提示、忽略单独的修饰键、Esc 取消；
- 存到 `settings.json` 的 `hotkey`（默认 `Ctrl+Alt+Space`）；
- 旧版鼠标绑定会自动迁移：`mouse-middle/back/forward` → `mouse2/mouse4/mouse5`；
- 注册失败（被占用/非法）会提示，并保持原热键可用。

## 12. 复制/粘贴高亮

- `y`（复制）和 `p`（粘贴）之后，相关卡片会闪一下；
- 设置 → 外观 → **复制/粘贴高亮**：颜色 + 时长（0 = 关闭），默认白色 260ms。

## 13. 改键交互补充

- 编辑弹窗字段导航：`Esc` 离开输入框进入字段导航（蓝框），`j/k` 换字段，`Enter` 进入该字段；输入框内仍可用 `Ctrl+J/K`。

- 捕获提示是**浮动**在窗口顶部的横幅，不再挤占列表；
- 捕获期间按 **Esc** 只取消捕获，不会关闭设置；
- 捕获期间**用鼠标点别处**会立即中断等待输入；
- 设置界面打开时，主界面的快捷键全部失效（`Ctrl+C/V` 等不会串台）；
- 主界面按 `Tab` 不再移动浏览器焦点框。

## 14. 新增：q 退出多选

`q` 与 `Esc` 一样清空选择并退出多选模式（**主界面与回收站都生效**），且可改。


## 15. 右键与鼠标组合（可绑定）

- 右键（`mouse3`）默认绑定到「编辑信息」，可在按键表里改；
- 支持任意「修饰键 + 鼠标键」：`ctrl+mouse1`、`shift+mouse1`、`ctrl+shift+mouse1`；
- 捕获时右键也能直接录入（录制期间不会弹系统菜单）；
- 未绑定的鼠标组合保持原有默认行为。

## 16. 全局热键：可选

- 设置 → 按键 → **系统快捷键**：
  - 呼出快贴面板（默认 `Ctrl+Alt+Space`，可改、可**禁用**）；
  - 剪贴板捕获开关（默认**未设置**，可选）；
- 不设置也能正常用托盘和界面按钮，不会强制占用系统热键；
- 禁用后写入空字符串，重启保持禁用。

## 17. 编辑弹窗「打开方式」

编辑表情 → **打开方式**：用系统默认图片查看器打开原文件（`ShellExecuteW`）。


## 18. 筛选面板与快捷键

- 筛选面板打开时，主界面快捷键全部失效（和设置一致），`Esc` 只关闭面板；
- 只有「筛选」一个按钮，启用时会高亮；清空在面板里的「清空」；
- 筛选是全局的（不是“只在当前视图内生效”），主界面与回收站都会应用。

## 19. 标签 / 分组输入规则

编辑弹窗、批量选择器、筛选标签都采用同一套交互：

1. 默认只显示按字母序的**前 3 个**候选（输入框为空时）；
2. 输入文字实时过滤候选；
3. `Tab` 补全第一个候选；
4. `Enter`：
   - 输入内容与已有名称完全匹配 → 选中它；
   - 不匹配且允许新建（编辑/分组）→ 新建；
   - 筛选标签不允许新建，只接受已有标签。

## 20. 最近使用上限

设置 → 常规 → 「最近使用上限」（10–1000，默认 60），快贴面板按这个上限取数，改完重启面板生效。


## 21. 界面补充

- 顶栏右侧新增**剪贴板捕获胶囊**（绿点=开、灰=关），点击即可切换，和设置/热键三处同步；
- 设置标题栏的「保存并关闭」**吸顶固定**，滚到哪都能点；
- 所有下拉框统一了样式（自绘箭头、深色/浅色跟随主题）；
- 编辑弹窗、批量选择器、筛选面板的标签/分组输入：候选框贴在输入框正下方，只显示前 3 个，`Tab` 补全、`Enter` 确认/新建。


## 22. 来源与批量输入

- 来源是**独立、不可编辑**的横向 chips：全部来源 / 本地导入 / 剪贴板 · 微信 / 剪贴板 · Snipaste…；
- 本地导入统一合并成一条，其它来源按进程合并，常见进程显示中文名（微信、QQ、Telegram、Discord、Snipaste 等）；
- 悬浮信息里也显示「来源」；
- 批量「加入分组 / 加标签」改成浮层：标题和输入框同一行，候选**向上展开**（因为它在屏幕底部），直接显示前 3 个，输入实时过滤，`Tab` 补全，`Enter` 确认或新建；
- 筛选面板里的标签候选会**浮在面板之上**，不再被容器裁掉。
