## 6. 已知坑（会重复踩的）

- **单实例锁**：`127.0.0.1:47821`。用户开着 App 时测试实例会重试 3s 后静默退出（日志 `[singleton] … 一直被占用，退出`）；`scripts/accept.ps1` 开头会强杀 `picarium` 进程（会关掉用户正在用的 App，跑之前先说一声）。
- **MSYS 路径**：`PICARIUM_HOME`/`PICARIUM_CONFIG_HOME` 必须传 Windows 绝对路径（`C:/...`）；传 `/c/...` 会被解析成 `C:\c\...`，App 回退打开真实库（踩过一次，改写了真实库 `index.json`）。
- **accept 计数**：报告在 `%TEMP%\picarium-accept\lib\selftest-report.json`；`%TEMP%\stickerbox-accept*` 是旧目录，读到 165 是假的。
- **`sed -i` 不能改含 PowerShell `$变量` 的行**（静默不生效），改 `scripts/*.ps1` 用 `edit` 工具。
- **jniLibs 残留**：改 crate/lib 名后 `src-tauri/gen/android/app/src/main/jniLibs/*/libstickerbox_lib.so` 旧符号链接会把旧 so 打进 APK，改名前清掉。
- **图标缓存**：换 exe 图标后资源管理器可能还显示旧图；`ie4uinit -show` + 重启 Explorer + 删 `iconcache_*.db` 才行（用户已知）。
- **模拟器**：用 `ops_bash` 后台直接跑 `emulator.exe`，别用 `scripts/android-emu.ps1`（会弹终端）；模拟器起来后不要关。
- 测试数据只放 `.demo/` 或系统临时目录；不要碰 `D:/test/pic` 和 `C:\Users\13066\Picarium`（只读确认可以）。
