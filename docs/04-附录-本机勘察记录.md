## 3. 微信自定义表情

### 3.1 定位

```bash
find "Documents/WeChat Files" -maxdepth 4 -type d -iname "*CustomEmotion*"
```

```
./wxid_o655luydga6m22/FileStorage/CustomEmotion
./wxid_xanbhvamzb2m21/FileStorage/CustomEmotion
```

两个账号目录，其中 `wxid_xanbhvamzb2m21` 为空，实际数据在 `wxid_o655luydga6m22`。

### 3.2 规模

| 指标 | 值 |
|---|---|
| 文件数 | 1464 |
| 总大小 | 100 MB |
| 文件名 | 32 位大写十六进制（MD5 形态），**无扩展名** |
| 目录结构 | `CustomEmotion/<2 位十六进制>/<32 位哈希>` |

### 3.3 文件头

```
000000  56 31 4d 4d 57 58 8c ab 47 dc a3 2b 26 ae fb 85   V1MMWX..G..+&...
```

- 前 6 字节固定 `V1MMWX`（`56 31 4D 4D 57 58`），300 个样本 100% 命中。
- 第 7–8 字节每文件不同。1464 个文件里只有 **1024 种**取值，且分布明显不均：

```
b'\x08\x8f' × 91    b'\xc7\x98' × 71    b'\xa2\x13' × 44
b'H\x8d'    × 27    b'\x7fQ'    × 16    b'\xfd.'    × 12
```

> 若这两字节是随机 IV，1464 个文件应几乎全不重复。出现高频重复说明它更像**密钥/版本索引**，而不是 IV。

### 3.4 密码学性质测试

| 测试 | 方法 | 结果 | 推断 |
|---|---|---|---|
| 块对齐 | 统计 `(size - n) % 16 == 0` 的比例，n ∈ [0,19] | 最高仅 7.8%（n=12），随机水平 | **不是 ECB/CBC** |
| ECB 重复块 | 最大文件（4.37 MB）按 16 字节切块，统计重复 | 273388 块中仅重复 10 块 | 无 ECB 特征 |
| 固定 XOR 密钥 | 300 个文件同偏移字节的众数占比 | 256 个位置里 **0 个** > 90% | 不是固定单字节/固定密钥流 |
| 密钥流周期性 | `C[i] ^ C[i+p]` 的零字节比例，p ∈ {16…4096} | 0.004–0.034，无尖峰 | 无短周期 |
| 压缩 | `zlib.decompress` / raw deflate | 均失败 | 不是压缩混淆 |
| 熵 | 单文件 36640 字节中 256 种字节值全部出现 | 接近均匀 | 加密或高熵编码 |

**结论**：`V1MMWX` 是真实的流式加密（或等价变换），密钥随文件/账号变化。**不存在「改个扩展名」或「单字节 XOR」的捷径。**

### 3.5 对方案的影响

### 5.2 验证 `V1MMWX` 魔数

```python
import os
from collections import Counter
root = r"...\CustomEmotion"
c = Counter(open(os.path.join(r, f), 'rb').read(6) for r, _, fs in os.walk(root) for f in fs)
print(c.most_common(3))   # [(b'V1MMWX', 1464)]
```

### 5.3 排除 ECB

```python
import os
from collections import Counter
root = r"...\CustomEmotion"
big = max((os.path.join(r, f) for r, _, fs in os.walk(root) for f in fs), key=os.path.getsize)
body = open(big, 'rb').read()[7:]
blocks = [body[i:i+16] for i in range(0, len(body) - 15, 16)]
print(len(blocks), len(Counter(blocks)))   # 273388 273378 → 无意义重复
```
