## 2. 复现命令

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:NDK_HOME   = "$env:LOCALAPPDATA\Android\Sdk\ndk\28.2.13676358"
$env:JAVA_HOME  = "C:\Program Files\Android\Android Studio\jbr"

npx tauri android init --ci        # 只在首次
npx tauri android build --debug --apk --target x86_64 --ci
```

产物：

```
src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
```

安装：

```powershell
adb install -r <apk>
adb shell monkey -p dev.stickerbox.desktop -c android.intent.category.LAUNCHER 1
```

## 3. 环境坑（已绕过）

1. **Rust target 下载慢**：直连 static.rust-lang.org 只有 ~40 KB/s。
   用镜像：
   ```powershell
   $env:RUSTUP_DIST_SERVER = "https://rsproxy.cn"
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   ```
2. **Gradle 下载慢 / 连接被拒**：
   - `~/.gradle/gradle.properties` 里配了 `127.0.0.1:7890` 代理，但代理没开；
   - 已把四行 `systemProp.*proxy*` 注释掉（原文件备份 `~/.gradle/gradle.properties.bak-stickerbox`）；
   - wrapper 改用腾讯镜像：
     `https://mirrors.cloud.tencent.com/gradle/gradle-9.6.1-bin.zip`；
   - 以后开代理再构建，可以恢复那四行或改用 `GRADLE_OPTS`。
3. **Gradle 9.6.1 + JDK 21** 会有 source/target 8 的警告，不影响构建。
