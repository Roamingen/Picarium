安卓字体设置 Android

把 PC 上的 Zed 式字体设置搬到手机：界面 / 列表与卡片 / 详情与浮层三档可以各自选西文、中文、回退链和字号。安卓 WebView 不能枚举系统字体，所以来源只有系统通用族和用户导入的字体文件；Nerd Font 不是特殊通道，导入后就是一个普通字体。

系统通用族 + 导入 3 个作用范围 NF 当普通字体 字号 12–20 不改卡片 / 控件高度 PC 端 mock →
01

先选来源，再选字体

系统只暴露 sans-serif / serif / monospace / sans-serif-condensed 四个通用族；要固定中文字形或图标，必须导入字体文件。

02

西文、中文、回退分开

每个作用范围都有独立的 Latin、CJK 和回退链；列表 / 详情默认跟随界面，关掉跟随才单独覆盖。

03

字体只影响文字

卡片、网格、按钮和底部选择器的高度不变；字号上限建议 18，先在小屏和长文件名下验收。

!
平台边界（先说明）：安卓 WebView 没有 queryLocalFonts 一类的枚举能力，也不会暴露“微软雅黑 / 思源黑体”这样的系统家族名。本稿只列 4 个通用族 + 导入文件；列表里预置的三个“导入”字体是演示数据，真实导入流程在底部选择器里。Nerd Font 同样从文件导入，之后只作为普通字体出现在列表里，没有全局开关。

实现备注

实现批按这份规格走，不是 mock 表面

字体栈：西文 → 中文 → 回退 → 系统兜底

每个作用范围只生成一条 CSS 字体栈。Nerd Font 不是单独的符号槽，它只是西文、中文或回退链里被选中的某个家族。

font-family:
  var(--latin),
  var(--cjk),
  var(--fallback-1),
  system-ui,
  sans-serif;

Nerd Font：普通字体，不做 unicode-range

导入后它就是字体列表里的一个家族，带 NF 徽标。放在回退链里时，只有前面字体缺字的 PUA 图标会落到它；选成西文主字体时，Latin 也会跟着变成 NF 的等宽字形，这是用户的选择，不再有全局开关。

/* 普通导入字体的 @font-face；没有 unicode-range */
@font-face { font-family: "导入的 NF"; src: url(blob:…); }
font-family: var(--latin), "导入的 NF", system-ui, sans-serif;

来源与导入：ttf-parser 读 family / cmap

安卓 WebView 不能枚举系统字体，只能列 4 个通用族；导入文件用 ttf-parser 读 family 与 cmap，按是否含「汉」、是否等宽、是否含 PUA，标 中文 / 等宽 / NF 徽标。TTC 取第一个字面，文件复制到 App 私有目录，卸载时一起删除。

字体选择列表只刷新「导入」分组；不存在「刷新系统字体」这个动作。

持久化、入口与验收

设置写进 settings.json 的 fonts 段，和 PC 同构，安卓多一份 imported 文件清单；启动时先注册 FontFace 再套字体栈。入口是 我的 › 外观 › 界面字体，打开全屏字体页，摘要显示当前西文 / 中文 / 字号 / 跟随状态。

验收在 12 / 14 / 16 / 18 / 20 五档、长英文名、中文、NF 图标和浅 / 深主题下看：列表标题截断、选择器行不撑高、底部 sheet 不遮按钮、无横向溢出。

已定方案（2026-11-07）

  1. 作用范围 3 档：界面 / 列表与卡片 / 详情与浮层；输入框、标签编辑器不单拆，跟着所属页面走。
  2. 字体来源选 A：系统通用族 + 用户导入；不内置字体文件，包体不变。
  3. Nerd Font 当普通字体：不做全局开关、不做 unicode-range 符号槽；导入后在列表里直接选，选中才用它的字形。
  4. 字号滑杆 12–20，默认 14；20 是允许上限，长文本和 320px 窄屏建议先按 18 验收。
  5. 每档可设字号 / 行高 / 字重；字距和 OpenType 特性手机端先不做。
  6. 列表 / 详情默认跟随界面；关掉跟随才复制一份当前值独立改。

本轮不做

  1. 导入字体的删除 / 重命名：等文件管理一起做。
  2. 按页面单独拆输入框 / 标签编辑器的字体。
  3. 方案 B（内置开源字体）和方案 C（只跟系统）。
