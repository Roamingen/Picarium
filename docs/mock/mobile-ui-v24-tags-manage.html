设计说明

标签生命周期

01 创建管理页新建，或加到图上新建的 0 引用标签也会登记。
→
02 使用计数 = 图片数标签列表按使用次数排序。
→
03 移出从图片上点 ×只影响这一张图，保存后生效。
→
04 删除删到 0 引用也保留只有「删除标签」才从登记表移除。

“删除标签”= 从所有图片移出 + 从登记表移除；图片本身不受影响。

单图编辑（A）

  • 入口是详情页标签行的「+ 标签」，替换现有占位 toast。
  • 面板 scope 是「这张图」，已选=这张图现有标签。
  • 点已选 chip（或 ×）移出；点未选 chip 添加；搜索框可新建。
  • 保存才生效：关闭/返回=放弃，避免误触改数据。
  • 保存后本地回写 a.tags 并刷新 tag_stats，详情行立即可见。

管理动作（B / C / D）

  • 重命名：全库同步改字符串；改成已有名字 → 直接转合并。
  • 合并：源标签删除，图片改挂目标；同一张图只算一次，计数相加。
  • 删除：二次确认；从所有图片移出；图片本身不删。
  • 三个动作都不可撤销；删除/合并前必须确认。
  • 没有“空标签”吗？有：管理页新建的标签计数为 0，仍保留到显式删除。

入口与取舍

标签管理我的 → 标签管理 6 个

标签面板右上也有「管理」，不用退回“我的”。

本批多选面板保持“只加”；批量移出容易误删，等单图编辑稳定后再加“移除”模式。

  • 单图保存用 set_asset_tags 一次写完；关闭/返回放弃。
  • 命令层：commands.rs 加对应命令，lib.rs + main.rs 注册。
  • 管理页数据仍来自 tag_stats（现在包含 0 引用登记项，次数倒序）。
  • 测试点：空白/重名、合并去重、删到 0、单图移出最后一张、回收站里旧标签不复活。
