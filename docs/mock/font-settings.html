实现备注

给确认后的实现批，不是 mock 表面

CSS 变量：按角色，不按元素

每个角色一组变量，主窗、快贴面板、手机端都从这里取；具体元素用 em 保留层级，不逐个改 font-size。

--ui-font / --ui-size / --ui-line
--ui-weight / --ui-letter / --ui-feat
--list-*  列表卡片
--panel-* 快贴面板
--mono-*  快捷键 / 路径

Nerd Font：只接管 PUA

用 @font-face + unicode-range 生成一个符号槽，插在字体栈末尾；NF 的等宽 Latin 不会抢走正文。字体不内置，PC 用 local() 读已装字体。

@font-face {
  font-family: "SB Nerd Symbols";
  src: local("JetBrainsMono Nerd Font Mono"),
       local("JetBrainsMono NFM");
  unicode-range: U+E000-F8FF,
    U+F0000-FFFFD, U+100000-10FFFD;
}

持久化：一份 settings，两个窗口

主窗和 panel.html 读同一份 `settings.json` 的 `fonts` 段；面板入口早于主窗时也要能拿到。未知字段忽略，缺字段补默认。

"fonts": {
  "version": 1,
  "roles": {
    "ui": { "latin": "...", "cjk": "...",
      "fallbacks": [], "size": 13,
      "line": 1.55, "weight": 400 },
    "list": { "follow": "ui" },
    "panel": { "follow": "ui" },
    "mono": { ... }
  },
  "nerd": { "enabled": true, "family": "..." }
}

枚举、导入与验收边界

PC 用 DirectWrite / font-kit 列家族，并用 cmap 判断是否含中文 / 等宽 / PUA；安卓 WebView 不枚举，只列通用族和导入列表（导入后用 ttf-parser 读 family/cmap）。

验收要在 11 / 13 / 15 / 18 四档、长英文、中文、NF 图标下看：卡片标题省略、设置行不撑高、kbd 不换行、无横向溢出。

需要你拍板

  1. 作用范围够不够？现在是 界面 / 列表与卡片 / 快贴面板 / 等宽。输入框、标签编辑器要不要再单独一档？
  2. 安卓字体来源选 A. 系统通用族 + 用户导入（推荐，0 包体）、B. 内置 1–2 款开源字体（+1–3MB，开箱即用）、还是 C. 只跟系统？本稿画的是 A。
  3. Nerd Font 默认开还是关？本稿 PC 默认开；安卓稿也是开（演示字体）。
  4. 字号上限 18 还是 20？本稿滑杆到 20，备注建议 18 以内防止裁切。
  5. PC 要不要也支持「导入字体文件」？本稿 PC 只列系统字体（Zed 式），安卓才导入。
