## 设计规格（改的时候照这个来）

**画布**：1024×1024，`viewBox="104 103 1046 1046"`；圆角方块 `rx=187`；
背景对角渐变 `#63A9FB → #4180FA(.35) → #2A64F3(.62) → #1C53EA(.85) → #1547D8`。

**罐子**：盖 = evenodd 胶囊（y 327..443，r58，内嵌嘴槽 r18.5）；罐身白描边 46、圆头圆角，Catmull-Rom 曲线（最窄 x≈277，底 y≈955）。

**水**：裁切在罐内；顶部波浪水面带 + 浅色高光；两颗气泡 (847,554) r39、(874,691) r17。

**三张纸**：同一个平行四边形 **T(576,551) R(846,650) B(656,755) L(385,656)**，圆角 26；
分别下移 71 / 128；每张下面垫 52 宽的水色描边当光晕，纸与纸之间自然露出 26 宽蓝缝。

**折角（定稿版）**：等腰直角三角形 —— 顶点 `(704,644)`，两个底角 `(674,750)`、`(810,674)`；
两腰 110（相等）、顶角 90°、深度 78；圆角 22；裁到最上层纸内（底边跟着纸的侧边）；
渐变 `#5587FD → #7BA3FE → #A6C2FE → #C4D8FE`，最深在折痕一侧，向左下尖变浅。
