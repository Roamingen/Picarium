删除标签「梗图」？
会从标签登记表和全部图片里移除它，回收站里的图片同样生效；图片本身不会被删除。
当前 5 张图片使用「梗图」。删除后这些图片只是不再是「梗图」，其它标签和分组不受影响。
另外两处一起对齐（实现时改，不在本预览里画）
1. 筛选面板的「标签」区右上加「管理」链接，点开同一个弹窗（和安卓筛选面板里的「管理」一致）。
2. 桌面编辑弹窗保存标签后，立即刷新 allTags，让新标签当轮就出现在筛选与批量面板里——这是这批里那段 core 修复的用户侧效果。
