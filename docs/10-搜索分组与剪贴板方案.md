# 10 · 搜索、分组、导入与剪贴板方案

> 2026-10-29 · 本轮实现 + 下一轮设计

---

## 1. 拼音搜索

### 1.1 实现

导入和改名时把名字转成两份索引字段，存进 `index.json`：

| 字段 | 「无语」 | 「猫猫1」 |
|---|---|---|
| `py` | `wuyu` | `maomao1` |
| `py_abbr` | `wy` | `mm1` |

搜索时不用再转换，直接比较；老库打开时自动补算（迁移零成本）。

### 1.2 排序权重（可调）

| 命中方式 | 分数 |
|---|---|
| 标题完全相同 | 1000 |
| 标题前缀 | 900 |
| 全拼相同 | 860 |
| 全拼前缀 | 820 |
| 首字母相同 | 800 |
| 首字母前缀 | 780 |
| 标题包含 | 600 |
| 全拼包含 | 520 |
| 首字母包含 | 500 |
| **标签完全相同** | 420 |
| **标签包含** | 320 |
| 分组包含 | 260 |
| 扩展名 | 200 |

同分时按导入时间倒序。

**设计取向：标题优先于标签。** 理由：你记得住名字时，名字是强意图；标签是宽泛分类，容易把结果淹没。
如果你更希望"标签优先"，改一个数字就行。

## 2. 分组（表情包）

### 2.1 模型

分组名直接存在 asset 上：`groups: ["猫猫", "工作"]`。

- 一个表情可以同时属于多个分组（和微信的"表情包"不同，但更灵活）；
- 没有分组 = **未分组**，侧栏单独一项，就是剪贴板捕获的默认去处；
- 分组名即身份，不支持重命名级联（后续可加"合并/改名"）。

### 2.2 交互

- 侧栏：全部 / 未分组 / 各个分组（带数量）
- 编辑框里第三个字段就是分组，支持多个、逗号分隔、自动补全已有分组
- 搜索框输入分组名也能命中（权重低于标签）

## 3. 导入方式

| 方式 | 实现 |
|---|---|
| 选择文件夹 | `tauri-plugin-dialog` 原生目录选择器 |
| 选择图片 | 原生文件选择器，可多选，按扩展名过滤 |
| 拖拽 | 监听 `tauri://drag-drop`，文件/文件夹都支持 |
| 粘贴路径 | 输入框回车 |

四种最终都走同一个 `import_paths`：目录递归扫描，文件直接入库。

## 4. 剪贴板捕获（下一轮实现）

### 4.1 机制

Windows 没有"剪贴板变化事件"的高级 API，两个选择：

| 方案 | 成本 | 可靠性 |
|---|---|---|
| `AddClipboardFormatListener` + 隐藏窗口 | 中（要建消息窗） | 高，实时 |
| 轮询 `GetClipboardSequenceNumber()` 每 250ms | 低 | 高，延迟 ≤ 250ms |

先用轮询：一个序号整数，几乎零开销，出问题也好排查。后续要更快再换监听。

### 4.2 流程

```
每 250ms 读一次剪贴板序号
      │ 变了？
      ▼
尝试按顺序取：PNG → CF_DIB → CF_DIBV5
      │ 拿到像素？
      ▼
编码 PNG → 算 SHA-256
      │ 库里已有？
      ├── 有 → 只记一次「复制事件」，不重复入库
      └── 没有 → 入库：
                 groups = ["未整理"]
                 tags   = [来源应用名]     ← 微信 / QQ / 浏览器 / 其他
                 source = clipboard
```

### 4.3 你问的「是不是所有软件复制的图片都会入库」

**是，所有软件。** 不维护白名单——白名单会让你在某天换了新软件后困惑"为什么没进来"。
取而代之：

- 每张图都记**来源应用**（取复制瞬间的前台窗口进程名），作为标签 + 元信息；
- 托盘菜单提供**暂停捕获**开关；
- 想按应用过滤，后续加"排除列表"（比白名单更符合直觉）。

### 4.4 边界情况

| 情况 | 处理 |
|---|---|
| 从本应用复制出去 | 入库时 SHA 已存在 → 去重，不会重复 |
| 同一张图复制两次 | 只记使用次数，不新增 |
| 超大截图（> 20 MB） | 跳过并提示（可配置） |
| 剪贴板里是文件路径而非位图 | 走 `import_paths` |
| 复制的是文字 | 忽略 |
| 动画 GIF | 剪贴板只剩首帧，这是系统限制；要原图请用拖拽/导入 |

### 4.5 隐私

- 只在本机内存里读，不落盘中间态；
- 暂停开关放托盘一级菜单；
- 库本身不加密时有风险（截图里可能有聊天记录），文档会提示。

## 5. 协作约定（给用户）

我占用鼠标/前台窗口只有一种情况：**需要看界面**（截图、定位窗口）。

建议的配合方式：

1. 我尽量把界面验证**攒成一批**，一次占用 1–2 分钟；
2. 你正在专注做事时，直接说「先别动界面」，我就只写代码不截图；
3. 需要验证但你不方便时，我把要点的按钮/位置写清楚，你点一下告诉我结果；
4. 我的自动操作**不会修改你的数据**（只在测试库/临时目录里折腾，最后一轮清理）。
