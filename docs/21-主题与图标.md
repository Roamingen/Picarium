### 自定义 JSON

把文件放到库根目录的 `themes/` 下：

```
C:\Users\13066\StickerBox\themes\my-theme.json
```

格式：

```json
{
  "name": "我的主题",
  "dark": true,
  "colors": {
    "--bg": "#1e1e2e",
    "--surface": "#181825",
    "--surface-2": "#313244",
    "--surface-3": "#181825",
    "--modal": "#1e1e2e",
    "--line": "#45475a",
    "--line-2": "#585b70",
    "--fg": "#cdd6f4",
    "--dim": "#a6adc8",
    "--dim-2": "#6c7086",
    "--accent": "#89b4fa",
    "--accent-fg": "#b4befe",
    "--danger": "#f38ba8",
    "--chip": "#313244",
    "--hover": "#313244",
    "--active": "#45475a"
  }
}
```

- `name`：下拉里显示的名字；
- `dark`：`true` 用深色基底、`false` 用浅色基底（未写的 token 回退到基底）；
- `colors`：键就是 CSS 变量名（必须以 `--` 开头），写上就会覆盖；
- 改完打开设置会自动重新扫描；也可以重启。

完整 token 列表见 `app/ui/style.css` 顶部两个 `:root` 块。Catppuccin 四套的完整映射在 `app/themes/*.json`，可以直接复制改。

## 2. 图标

- 图标库：[Lucide](https://lucide.dev)（ISC 许可），内嵌 SVG，不依赖网络；
- 已替换：设置、置顶、导入文件夹、导入图片、筛选、清空回收站、新建分组、搜索清空、多选；
- 图标通过 `app/ui/app.js` 里的 `ICONS` 映射 + `icon(name, size)` 生成；
- 新增图标：把 Lucide 的 path 内容加进 `ICONS`，然后在 `paintIcons()` 里绑定。

许可证：Lucide 图标为 ISC License，可商用；本项目仅内嵌所需子集，未引入运行时依赖。
