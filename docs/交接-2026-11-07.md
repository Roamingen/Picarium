## 2. 现在在哪

用户能用：

- **设置 › 外观 › 界面字体** 一行，摘要显示「西文 / 中文 · 字号 · 列表跟随」；右侧「字体…」打开独立字体窗口。
- **字体窗口**：220px 角色列表 / 中间可滚动表单 / 右侧实时预览。
  - 4 个作用域：`ui` 界面、`list` 列表与卡片、`panel` 快贴面板、`mono` 等宽。
  - 每档可设：西文字体、中文字体、最多 5 个回退（增删/上下移）、字号 11–20、行高、字重、字距、OpenType 特性。
  - `list` / `panel` 默认跟随 `ui`；取消跟随时复制一份 UI 当前值，可独立改。`mono` 默认独立。
  - 字体选择器：搜索、手动输入字体名、系统字体列表（本机 241 个 family）、中文过滤（27 个）、NF 字体仅作为普通字体带 `NF` 徽标。
  - 底部「恢复默认」只改草稿；「应用」写设置并发 `fonts-changed`；「取消」/Esc 丢弃草稿并重新渲染。关闭窗口复用同一个 `font` 窗口。
- **主窗**：字体变量立即生效；字号只影响文字，不改卡片/网格/控件尺寸。20px 是允许上限但偏紧，设计建议 18 以内。
- **快贴面板**：加载 `font-config.js`，监听 `fonts-changed`；搜索/计数/底栏按 panel 档放大，快捷键/路径/数量按 mono。
- **重启持久化**：设置存 `settings.json` 的 flat `fonts` 字段；重启后主窗与面板仍是上次值。已验证 16px Cascadia + Noto Serif SC + 回退 Cascadia 的组合。

## 6. 已知坑（会重复踩的）

1. **Tauri 同步命令里创建窗口会死锁**：`show_font_settings` 必须 `async`；同步版本会让字体窗口白屏、所有 IPC 一起超时。
2. **前端资源编进二进制**：改 `src-tauri/ui/*` 后必须 `cargo build -p stickerbox`；只重启 exe 不生效。构建前先停掉 `stickerbox.exe`。
3. **CSS 类名前缀要查全局冲突**：字体窗口原来用 `fp-*`，撞上 `src-tauri/ui/style.css:2699` 的 `.fp-field`（筛选面板），导致标签竖排、按钮缩进 56px；已全部改 `fw-`。新增窗口/面板类名前先 `rg`。
4. **字体栈去重**：`SBFonts.stack` 会去掉重复 family（如拉丁和回退都选 Cascadia）；这是预期，不要当丢设置。
5. **CJK 判定只按「汉」glyph**：`list_system_fonts` 用 U+6C49 判断；241 个 family 中 27 个标记中文。别拿 `monospaced` 当等宽显示的唯一依据。
6. **20px 偏紧**：主窗空状态/顶栏长文本会换行或截断；卡片/控件尺寸不缩放。设置弹窗已加宽到 620，但 20px 下仍建议 18 以内。
7. **列表角色目前只作用于 `.tip` 悬浮信息**：主窗卡片没有标题/标签文字；等宽作用于路径、数量、`kbd`；面板角色作用于搜索/计数/底栏。验收时如实说明。
8. **CDP 端口**：真实 Tauri 用 9223（`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9223`）；旧的 9222 是 Chrome mock，已清理。字体窗口和主窗都是 target，截图要选对窗口。
9. **测试库**：`$TEMP/stickerbox-fontverify/lib`；真实库 `C:\Users\13066\StickerBox` 不许碰。
10. **`accept.ps1` 日志**：`.demo/accept-font2.log`；`.demo/` 全 gitignore，截图/脚本不入库。
