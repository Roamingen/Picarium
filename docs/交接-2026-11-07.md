## 6. 已知坑（会重复踩的）

1. **Tauri aarch64 release 叫 universal**：产物是 `app-universal-release.apk`，不是 arm64 命名；不要按文件名找。`scripts/release.ps1` 现在会检查 zip 的 `lib/<abi>/`，只允许 arm64-v8a。
2. **模拟器首次启动黑屏不是崩溃**：`mWakefulness=Asleep`；`adb shell input keyevent KEYCODE_WAKEUP` + `wm dismiss-keyguard` 即可。截图前确认屏幕已亮。
3. **`activeLayer()` 的 `sheetmask` 必须在 `fontmask` 前**：否则「放弃未保存修改」确认弹层会被字体页抢返回。
4. **`sans-serif-condensed` 必须进 `GENERIC`**：否则 `stackMobile` 会给它加引号，Android 无法命中系统窄体。
5. **入口摘要显示的是 UI 档**：把列表改成 Serif 16，入口仍显示 `sans-serif · 14px`，这是预期，不是没保存。
6. **release APK 是 arm64**：不能装 x86_64 模拟器；真机验证由用户做。`apksigner` 证书是 StickerBox release key，不是 debug。
7. **模拟器里已有测试设置**：列表 Serif 16、跟随关闭；不要随手重置用户数据/设置。
8. **adb 路径**：`$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe`，不在 PATH。
9. **release 目录**：`release/` 与 `.demo/` 不入库；不要 `git add` 截图/APK。
10. **改 `src-tauri/ui/*` 后**：桌面端要 `cargo build -p stickerbox`；安卓要重打 debug APK 才能看到 WebView 变化。
