# 08 · 本轮交付：快贴面板与托盘

> 2026-10-28 · 对应你的反馈：面板要简单、要大输入框、全键盘、关窗进托盘

---

## 1. 修掉的一个真问题：面板加载了错误的页面

`tauri.conf.json` 里面板窗口没写 `url`，Tauri 默认加载 `index.html`——所以你按快捷键看到的其实是**主窗口那套界面**，才会出现「扫描导入」区。

修法：`"url": "panel.html"`。

---

## 2. 面板重做（参考 PowerToys Run）

![快贴面板](panel.png)

| 你的要求 | 实现 |
|---|---|
| 简单，不要导入区 | 面板只有：搜索框 + 结果网格 + 快捷键提示 |
| 自动聚焦输入框 | 窗口显示时 `set_focus()`，前端再 `input.focus()` 兜底 |
| 输入框调大 | 22px，整行宽度，左侧放大镜图标 |
| 全键盘 | `↑↓←→` 移动选中，`Enter` 复制并关闭，`Esc` 关闭 |
| Enter 选第一个 | 默认选中第 0 项（按最近使用排序） |
| 像 PowerToys Run | 单行输入 + 下方结果 + 底部 `kbd` 提示；选中项高亮描边 |

细节：

- 输入防抖 60ms，空查询显示最近 60 张；
- 鼠标悬停会同步移动选中项，点击直接复制；
- 右上角显示「13 个结果」；
- 复制成功后自动关窗，回到聊天窗口直接 `Ctrl+V`。

---

## 3. 托盘

| 行为 | 实现 |
|---|---|
| 关闭主窗口 | 拦截 `CloseRequested`，改为隐藏，进程不退 |
| 托盘图标 | 32×32，来自同一套图标生成脚本 |
| 左键单击 | 显示主窗口 |
| 右键菜单 | 打开 StickerBox / 快贴面板 / 退出 |
| 快捷键 | 全局 `Ctrl+Alt+Space` 唤起面板 |

验证结果（脚本实测）：

```
process alive: 53336
main window visible: False
PASS: 关闭主窗口后隐藏，进程仍在
```

托盘图标与面板截图不入库。
