> 2026-10-31 记录。命令都在仓库根 `C:\Users\13066\dsh\bqb` 下执行。

## 1. 模拟器

SDK 路径：`C:\Users\13066\AppData\Local\Android\Sdk`

### 1.1 启动（带窗口）

PowerShell：

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
& "$env:ANDROID_HOME\emulator\emulator.exe" -avd Medium_Phone_API_35 -gpu swiftshader
```

bash / zsh：

```bash
export ANDROID_HOME="$LOCALAPPDATA/Android/Sdk"
"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd Medium_Phone_API_35 -gpu swiftshader
```

### 1.2 启动（无窗口，给脚本用）

在上面命令后加 `-no-window -no-audio -no-boot-anim -no-snapshot`。
无窗口时 `adb screencap` 可能白屏/陈旧，用 WebView CDP 截图（`scripts/android_shot.py`）更可靠。

### 1.3 查看/关闭

```bash
"$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe" devices
"$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe" emu kill   # 关掉正在跑的
```

任务管理器里残留的 `emulator.exe` 可直接结束。

### 1.4 常见错误

| 报错 | 原因 / 解决 |
|---|---|
| `Running multiple emulators with the same AVD ... use -read-only` | 已经有一个同 AVD 在跑。先 `adb emu kill` 或结束旧的 `emulator.exe`；确实要同时开两个才加 `-read-only` |
| `Neither ANDROID_SDK_ROOT nor ANDROID_HOME is set` | 只是警告；设 `ANDROID_HOME` 即可 |
| 启动就崩 / 画面纯白 | 无窗口 + `-gpu swiftshader_indirect` 在这台机器会 EGL 失败；用 `-gpu swiftshader` |
| `adb devices` 里是 `offline` | 还在启动，等 `sys.boot_completed=1` |

## 2. 安装 APK

```bash
ADB="$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"
"$ADB" install -r "src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk"
"$ADB" shell am start -n dev.picarium.desktop/.MainActivity
```

- **debug 与 release 签名不同**，互相覆盖安装会失败（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`）；换装前先
  `adb uninstall dev.picarium.desktop`（会清空测试库）。
- release 包不可调试（没有 `run-as`、没有 WebView 远程调试），验证靠 `adb screencap`。

## 3. 签名 keystore

- 位置：`C:\Users\13066\StickerBox-keys\stickerbox-release.jks`
- alias：`stickerbox`；密码、有效期写在同目录 `README.txt`
- **务必双备份**：丢了就无法给已安装用户覆盖升级（只能换包名重新发）。

### 3.1 新建（仅首次）

```bash
"C:/Program Files/Android/Android Studio/jbr/bin/keytool.exe" -genkeypair -v \
  -keystore C:/Users/13066/StickerBox-keys/stickerbox-release.jks \
  -alias stickerbox -keyalg RSA -keysize 2048 -validity 10950 \
  -dname "CN=StickerBox, OU=Mobile, O=StickerBox, L=Shanghai, ST=Shanghai, C=CN"
```

### 3.2 工程里的配置（已配好，勿提交）

- `src-tauri/gen/android/keystore.properties`（`storeFile/storePassword/keyAlias/keyPassword`），已在 `.gitignore`。
- `src-tauri/gen/android/app/build.gradle.kts` 读取它生成 `signingConfigs.release`。
- `proguard-rules.pro` 必须保留 JNI 桥的类名（R8 会改名/裁掉）：
  `ShareBridge` / `PickerBridge` / `InboxBridge` / `MediaCopy`。
  **踩过**：一开始只 keep 了 `ShareBridge`，release 包里分享收件箱和相册导入都静默失败
  （Java 侧还能调，Rust 侧按类名反射找不到），debug 包却正常。JNI 类一律整类 keep。

## 键盘遮挡（targetSdk 35）

`android:windowSoftInputMode="adjustResize"` 在 targetSdk 35 的 edge-to-edge 下不生效，
键盘会以 overlay 形式盖住内容。`MainActivity` 里用：

```kotlin
val ime = insets.getInsets(WindowInsetsCompat.Type.ime())
v.updatePadding(top = bars.top, bottom = maxOf(bars.bottom, ime.bottom))
```

把 WebView 缩到键盘上方，底部弹层的输入框才可见。
