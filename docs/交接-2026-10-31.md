## 5. 已知坑（别重复踩）

- **安卓 WebView 内部滚动容器合成错误**：卡片会画成 25px 彩条。规则：整页滚动 + `.topwrap` sticky + `.nav/.fab` fixed，不要给中间容器 `overflow-y:auto`。
- 作者样式会盖掉 `hidden`：`mobile.css` 顶部已有 `[hidden]{display:none!important}`，新增带 display 的组件要记得。
- WebView 可能比 Rust `setup` 里的 `app.manage(AppState)` 先跑：`invokeRetry` 会对 `not managed` 重试 25 次。
- JNI：`ndk_context` 给的是 **Application**，不是 Activity；Java 方法参数要写 `Context`，Rust 描述符 `(Landroid/content/Context;...)V`，否则 `JNI DETECTED ERROR ... bad arguments` 直接 abort。
- `content://` URI 无扩展名：必须读文件头（`MediaCopy.java`），按 URI 猜会把 PNG 存成 `.jpg` → 缩略图空白。
- 分享 `singleTask`：已运行时只走 `onNewIntent`，WebView 不重载 → 前端在 `focus`/`visibilitychange` 重查 `take_shared_paths`。
- `adb shell am start -a SEND --eu ...` 不带 URI 授权会 `SecurityException`，分享必须用真实分享面板（Photos → 分享 → StickerBox）验证。
- release 包不可调试（无 run-as / WebView 调试）；debug 与 release 签名不同，换装要先卸载（会清库）。
- **R8 会裁 JNI 桥**：`proguard-rules.pro` 必须 keep `ShareBridge/PickerBridge/InboxBridge/MediaCopy`，否则 release 里「分享到 StickerBox」「从相册导入」静默失效（debug 正常）。
- 无窗口模拟器 `adb screencap` 可能白屏/陈旧 → 用 CDP 截图。
- `accept.ps1` 用临时库（`%TEMP%\stickerbox-accept\lib`），不要对用户真实库做删除测试。
- Cargo 的 target-dir 在 `C:/Users/13066/AppData/Local/StickerBoxBuild/target`（工作区外），不要惊讶。
