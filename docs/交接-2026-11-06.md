## 6. 已知坑（会重复踩的）

1. **本机 `scripts/accept.ps1` 跑不了**：pwsh 里任何「原生命令输出进管道」都报 `ResourceUnavailable: Program 'cargo.exe' failed to run: 拒绝访问`，每个 Step 都会 FAIL。改用 `.demo/verify-a.sh`（同样步骤手工串）。它在自测前要先写 `$lib/themes/accept-theme.json`，否则「自定义主题」那条断言会挂。
2. **`cargo` 的 target-dir 在工作区外**（`.cargo/config.toml` → `C:/Users/13066/AppData/Local/StickerBoxBuild/target`），沙箱是 workspace-write 时会 `os error 5`；需要 danger-full-access。
3. **前端资源编进二进制**：改 `app.js`/`style.css`/`panel.html` 后必须 `cargo build -p stickerbox`，否则跑的是旧界面。
4. **隐藏窗口抓不了图**：WebView2 在 `--tray` 隐藏时不绘制，CDP 只回白帧；只能「屏幕外无激活显示」（`SW_SHOWNOACTIVATE` + `(-4000,-4000)`）。窗口枚举必须 `CharSet.Unicode` 且按 `class=="Tauri Window"` 过滤，否则会抓到 `tray_icon_app` 等空窗口出黑图。
5. **`.tools/` 被 `.gitignore:20` 忽略**，新增脚本要 `git add -f`。
6. **函数重名会静默覆盖**：`app.js:4012` 有老的 `startCapture`（改键面板用），新写同名函数会被提升覆盖 —— 已改名 `startPanelKeyCapture`。新增全局函数前先 grep。
7. **回收站不能用虚拟滚动**：`loadTrash()` 里 `grid.classList.remove('virtual')`，否则 resize 触发 `renderVirtual()` 会把角标和 EVA 框重建掉。
8. **手机端目前只有静态 harness**：`.demo/mh/` 用 stub `__TAURI__` 渲染，能验 CSS/文案/交互，验不了真机 WebView 与命令链路。
9. CDP target 里同时有 `panel.html` 和主窗，脚本要按 `!url.includes('panel.html')` 挑；手机 harness 的 Chrome 要配 `Page.reload({ignoreCache:true})`，否则改完 CSS 看到的还是旧的。
