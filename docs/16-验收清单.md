## 1. 自动验收（每次改动后跑这个）

```powershell
pwsh -NoProfile -File scripts/accept.ps1          # 默认不弹窗口
pwsh -NoProfile -File scripts/accept.ps1 -Shots   # 额外刷新 docs 截图
pwsh -NoProfile -File scripts/perf.ps1            # 3000 张性能基准（含预热）
```

自测时测试库会写入 `startHidden`，窗口不会弹出来抢焦点；`-Shots` 截图也不抢焦点——窗口在屏幕外无激活显示后抓帧（`.tools/shot_main.ps1`），前台窗口保持不变。

它会依次完成：

1. 杀掉旧进程；
2. `cargo build -p stickerbox`；
3. `cargo test -p stickerbox-core`（要求 `test result: ok`）；
4. 用临时库（`%TEMP%\stickerbox-accept`）导入 6 张示例图；
5. 以 `STICKERBOX_SELFTEST=accept` 启动，跑 117 条前端断言，结果写到
   `%TEMP%\stickerbox-accept\lib\selftest-report.json`；
6. 截图不入库，需要时本地查看；
7. 汇总并输出 `ALL PASS` / `RESULT: FAIL`（退出码 0/1）。

任何一项失败都会打印具体断言名与细节，不需要人工翻界面。

### 覆盖范围

| 区域 | 断言示例 |

| 计数 | `2j` 一次走两行 |
| 批量 | `s` 切换收藏、`y` 后自动退出多选、`p` 触发移动 |

## 2. 人工清单（只留机器测不了的，10 条）

每条只判 PASS / FAIL，不需要中间反馈：

1. **拖拽**：单张 / 多选拖到分组、拖到插入线排序、拖到回收站。
2. **粘贴**：微信或 QQ 里 `Ctrl+V`，位图能发、多文件能发、GIF 粘贴后仍动。
3. **快贴面板**：`Ctrl+Alt+Space` 呼出；GIF 悬停开始动；排序符合设置；位置/尺寸设置生效。
4. **光标环**：颜色与速度设置生效；连续 `j` 移动时环是连续流动的，不回到起点。
5. **改键**：设置 → 按键 → 把「向下」改成 `n`；立即生效；重启后仍保留；改成已占用的键会被拒绝。
   顺带试鼠标：把「加入分组」绑成 `ctrl+shift+mouse1`，再按住 Ctrl+Shift 点卡片。
6. **速查**：按 `?` 能看到分组好的完整按键表，`Esc` 关闭。
7. **空分组**：新建一个空分组，`Ctrl+J/K` 能切过去；回收站里能用 `j/k/x/v/Enter/dd` 全流程操作。
8. **主题**：深色/浅色切换后，按钮、提示、批量栏文字都可读。
9. **开机自启**：开启后重启系统，按设置是「显示主界面」还是「只留托盘」。
10. **设置备份**：导出 → 改几项 → 导入刚才的文件 → 配置恢复一致。
11. **系统热键**：设置 → 按键 → 系统快捷键 → 修改为空闲组合，确认新组合能呼出快贴；再点「禁用」确认旧组合失效；给剪贴板设置一个开关热键，按一下暂停、再按恢复。
12. **右键绑定**：按键表里把「编辑信息」改成右键或 `ctrl+mouse1`，确认点法变化。
13. **筛选**：按 `f` 或点「筛选」→ 勾「微信动图 ≤1MB」→ 只剩小图；来源下拉选「导入文件夹」；清空后恢复；回收站里同样生效。
14. **标签/分组输入**：编辑弹窗里输入「浏览」→ 上方出现「浏览器」，`Tab` 补全、`Enter` 加入；输入不存在的名字 `Enter` 直接新建；筛选面板的标签输入同样可 `Tab`/`Enter`。
15. **最近使用上限**：设置里改成 200，重启后快贴面板最多显示 200 条。
16. **剪贴板开关**：顶栏绿色胶囊显示「剪贴板捕获：开」，点一下变灰「关」，重启后状态保持。
17. **来源/批量面板**：筛选里的来源是横向 chips（本地导入只有一条，微信显示为「剪贴板 · 微信」）；多选两张点「加入分组」，浮层里直接显示前 3 个候选，输入可过滤、`Tab` 补全、`Enter` 新建/加入。
18. **分组显示**：在「全部」里右键一张属于某分组的图，编辑器应显示分组 chip；点 chip 的 × 再保存，分组应被移除。
19. **剪贴板黑名单**：设置 → 常规 → 剪贴板黑名单里默认有 `snipaste.exe`；用 Snipaste 截图复制，不应再入库。
