## 6. 已知坑（会重复踩的）

1. **封面角标**：`.gb` 的样式原先只写在 `.pc` 下面，放进 `.fc` 就没有样式 → 按正文字号渲染成巨大「G」。已把角标和那段 CSS 一起删了；封面现在直接 `<img src="${thumbUrl(g.cover, g.animated)}">`。
2. **Photo Picker 没有文件名**：`ACTION_PICK_IMAGES` 的 URI `DISPLAY_NAME` 就是数字 id（`1000000085`），`MediaStore.getMediaUri` 在这台模拟器上直接抛 `IllegalArgumentException: Provider for this Uri is not supported.`。要原名只能走 SAF。
3. **picker 在前台时 CDP 会挂住**：页面 `visible:false`，`Runtime.evaluate` 全部超时。先 `adb shell input keyevent 4` 关掉 picker 再连；命令行用 `timeout 8 … || true`。
4. **`am start` 模拟分享不成立**：`--grant-read-uri-permission` 授权不到 MediaProvider（`SecurityException: … has no access to content://media/…`），`am` 也不认 `-g`。分享入口只能真机验。
5. **`list_assets` 必须带 `q`**：签名 `(q, group, limit, sort, filters)`，漏了报 `invalid args \`q\``。
6. **PowerShell 跑 npx 不要 `$ErrorActionPreference = "Stop"`**：npx 往 stderr 写 Info 行会被当成错误直接中止，日志都不生成。用 `& npx … *>&1 | Tee-Object -FilePath …`（Tee 输出 UTF-16）。
7. **adb 与 MSYS**：`adb` 不在 PATH（用 `$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe`）；`/sdcard/...` 会被 MSYS 改写成 Windows 路径，先 `export MSYS_NO_PATHCONV=1`。
8. **debug 包启动白屏 6–8s**：Rust 初始化慢，截图要等。
9. **多选态收藏夹 `pointer-events: none`**：以后若想在多选里把它当拖拽目标，要单独放开，别直接改 `pointer-events`。
10. **桌面 release 与 debug 签名不同**：`adb install -r` 会失败，先卸载（安卓）。
