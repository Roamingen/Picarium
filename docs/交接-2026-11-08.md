## 6. 已知坑（会重复踩的）

1. **测试窗口纪律**：必须 `startHidden` + WebView2 CDP 在隐藏页断言；不要按 `Ctrl+Alt+Space`，不要 `Start-Process` 弹窗；本次 accept 用 `-WindowStyle Hidden`。用户对抢前台非常敏感。
2. **CDP 页面选择**：`http://tauri.localhost/panel.html` 与 `http://tauri.localhost/` 两个 page；按 URL 精确区分，不能用包含 `tauri.localhost` 的子串选主页面。
3. **CSS 覆盖**：v4 规则追加在 `style.css` 末尾；旧 header/sidebar/tip/menu 规则仍在，改旧规则可能被覆盖/互相打架，先查末尾块。
4. **封面动图**：`group_list` 的 `cover` 是 sha，动图必须用新增的 `cover_path`；不要把 sha 直接当文件路径。
5. **设为封面可见性**：smart view（`currentGroup` 以 `__` 开头）应隐藏；菜单统一循环 `[data-cm]` 时曾把 `hidden` 覆盖掉，需保留 `setcover && !canCover` 条件。
6. **组副标题**：现在是 `N 张表情`，不是封面动图数量；别把“张动图”当成整组数量。
7. **窗口/安装版**：构建/验收会停掉 `stickerbox.exe`；当前没有 release，安装版还是旧版；用户要正式看需先点头出 release/install。
